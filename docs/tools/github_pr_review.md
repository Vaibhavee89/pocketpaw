# GitHubPRReviewTool

**Tool Name:** `review_github_pr`
**Trust Level:** `standard` (read-only GitHub access)
**Created:** 2026-02-22

## Overview

The GitHubPRReviewTool is an AI-powered code review assistant that fetches GitHub pull requests and provides intelligent, comprehensive reviews. It integrates with GitHub via MCP (Model Context Protocol) and uses LLM analysis to identify issues, suggest improvements, and assess code quality.

## Features

- **GitHub MCP Integration**: Seamless OAuth-based GitHub access
- **AI-Powered Review**: LLM-based code analysis with focus areas
- **Multiple Depth Levels**: Quick, standard, or deep review modes
- **Flexible URL Formats**: Supports full URLs and short `owner/repo#123` format
- **Focused Analysis**: Target specific areas (security, performance, style, tests, docs)
- **Structured Output**: Professional, markdown-formatted review reports

## Prerequisites

### GitHub MCP Setup

This tool requires GitHub MCP server to be configured:

1. Open PocketPaw Dashboard
2. Navigate to **Settings > MCP Servers**
3. Enable **GitHub MCP server**
4. Complete **OAuth authorization** flow
5. Verify connection status shows "Connected"

**First-time Setup**:

```bash
# The GitHub MCP server is included with PocketPaw
# Just need to authorize via Dashboard OAuth flow
```

See [MCP Configuration Guide](../mcp/github.md) for detailed setup instructions.

## Parameters

### Required

- **`pr_url`** (string): GitHub PR URL or short format
  - Full URL: `"https://github.com/owner/repo/pull/123"`
  - Short format: `"owner/repo#123"`

### Optional

- **`review_depth`** (string): Review thoroughness level
  - Options: `"quick"`, `"standard"`, `"deep"`
  - Default: `"standard"`
  - **Quick**: Changed lines only (100 lines focus)
  - **Standard**: Changed lines + function context (500 lines focus)
  - **Deep**: Full file context (2000 lines focus)

- **`focus_areas`** (array of strings): Specific review focus
  - Options: `["security", "performance", "style", "tests", "docs"]`
  - Default: `["security", "performance"]`
  - Multiple areas can be selected

## GitHub MCP Integration

### Required MCP Tools

The tool uses these GitHub MCP endpoints:

1. **`get_pull_request`**: Fetch PR metadata
   - PR title, description, author
   - Status, labels, reviewers
   - Base and head branches

2. **`get_pull_request_diff`**: Fetch file changes
   - Full diff of modified files
   - Added/removed lines

3. **`list_pull_request_files`**: List changed files (fallback)
   - Used when diff is too large
   - Provides file list for analysis

### OAuth Permissions

Required GitHub OAuth scopes:
- `repo` (or `public_repo` for public repos only)
- Read access to pull requests

### Connection Verification

The tool automatically checks GitHub MCP status:

```python
# Internal check performed automatically
is_connected = await self._check_github_mcp(mcp_manager)

if not is_connected:
    return error_with_setup_instructions()
```

## Security Considerations

### Trust Level: Standard

This tool has read-only access:

- **No Write Operations**: Cannot modify PRs, create comments, or push code
- **OAuth Protected**: Tokens stored encrypted in `oauth_store`
- **Rate Limited**: Respects GitHub API rate limits
- **Audit Logged**: All PR fetches logged to audit trail

### Data Privacy

- PR content is sent to LLM for analysis
- Use with caution for private/sensitive code
- Respects repository permissions (user's GitHub access level)

## Error Handling

### GitHub MCP Not Connected

```
Error: GitHub MCP not connected. Configure it via Dashboard > MCP Servers.

Instructions:
1. Open PocketPaw Dashboard
2. Go to Settings > MCP Servers
3. Enable GitHub MCP server
4. Complete OAuth authorization
5. Retry this command
```

**Solution**: Complete GitHub MCP OAuth setup

### Invalid PR URL

```
Error: Invalid PR URL format: invalid-url

Supported formats:
• https://github.com/owner/repo/pull/123
• owner/repo#123
```

**Solution**: Use correct URL format

### PR Not Found

```
Error: Failed to fetch PR: 404 Not Found
```

**Causes**:
- PR doesn't exist
- Repository is private and user lacks access
- PR number is incorrect

**Solution**: Verify PR URL and access permissions

### Diff Too Large

When diff exceeds limits, tool falls back to file list:

```
Files changed:
file1.py
file2.js
file3.go

(Full diff not available)
```

**Result**: Review based on file list and metadata

### LLM Analysis Unavailable

```
LLM analysis unavailable. Here's the raw PR data:
[PR metadata...]

Manual review recommended.
```

**Fallback**: Returns raw PR information without AI analysis

## Performance Characteristics

- **PR Metadata Fetch**: 1-3 seconds
- **Diff Fetch**: 2-5 seconds (depends on PR size)
- **LLM Analysis**: 5-15 seconds
- **Total**: 8-23 seconds typical

**Depth Impact**:
- **Quick**: Fastest, analyzes fewer lines
- **Standard**: Balanced (recommended)
- **Deep**: Slowest, most thorough

**Large PRs** (>500 lines):
- Automatic truncation applied
- Focus on most critical changes
- May suggest splitting PR

## Limitations

1. **Read-Only**: Cannot post comments or request changes (yet)
2. **Public Access**: Respects user's GitHub permissions
3. **Context Window**: Very large PRs may be truncated
4. **GitHub Only**: Does not support GitLab, Bitbucket
5. **English**: LLM review is English-language only

## Troubleshooting

### Issue: "MCP server not connected"

**Cause**: GitHub MCP not configured
**Solution**: Follow setup instructions in error message

### Issue: "PR not found"

**Cause**: Invalid URL or no access
**Solution**: Verify PR exists and you have read access

### Issue: "Rate limit exceeded"

**Cause**: GitHub API rate limit hit
**Solution**: Wait for rate limit reset (check GitHub docs)

### Issue: Review is too generic

**Cause**: Standard depth on large PR
**Solution**: Use `deep` review depth or focus areas

### Issue: OAuth token expired

**Cause**: Token needs refresh
**Solution**: Re-authorize via Dashboard
